===============================================================================
AUTONOMOUS REVENUE RECOVERY AGENT — VIDEO DEMO SCRIPT & COMMANDS
===============================================================================

This step-by-step guide is designed for recording your demo video for the
Razorpay Buildathon (Track 03: AI Revenue Recovery).

Target Video Length: 3 to 5 minutes
Tabs to have open in browser before recording:
  1. Next.js Dashboard:  http://localhost:3000/cases
  2. Metrics Dashboard:  http://localhost:3000/metrics
  3. Approvals Queue:    http://localhost:3000/approvals
  4. Inngest UI:         http://localhost:8288
  5. Your Test Email / WhatsApp (to show live incoming recovery messages)

===============================================================================
PHASE 0: PRE-RECORDING SETUP (RUN ONCE BEFORE RECORDING)
===============================================================================

1. Ensure Docker Desktop is running.

2. Start PostgreSQL and Redis containers:
   docker-compose up -d

3. Push schema to PostgreSQL:
   npm run db:push

4. Reset database to a clean slate (0 cases):
   npm run db:clear

5. Start the web application (Terminal 1):
   npm run dev

6. Start the Inngest dev server (Terminal 2):
   npm run inngest:dev

7. Open a clean terminal window (Terminal 3) for executing demo commands.
